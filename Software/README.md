# Software

- `ATOM.ubl`: MicroBlocks library for ATOM localization, motion control, display, and communication.
- `Sonix OID AT - InfoWeavers_OID3_20241008_V7.11.456.758a9.30t(1).exe`: third-party utility used to design printable OID maps.

ATOM programs are developed with [MicroBlocks](https://microblocks.fun/). Import `ATOM.ubl` from the MicroBlocks library menu before opening the experimental programs.

The OID map utility is third-party software and remains subject to its original license and terms.
